Breakout – Slutprojekt i C#

 🎯 Mål
Ett klassiskt Breakout-spel med:
- Boll som studsar korrekt
- Block som försvinner vid träff
- Powerups (större paddel, extra boll)
- Highscore sparas i fil
- Objektorienterad struktur med ärvning

💻 Teknisk information
- Språk: C#
- Ramverk: Windows Forms
- Highscore sparas i `highscore.txt`

🗂️ Struktur
/Breakout
│
├── GameManager.cs
├── GameObject.cs
├── Ball.cs
├── Paddle.cs
├── Block.cs
├── PowerUp.cs
├── FileManager.cs
└── highscore.txt

 🧠 Betygsmål
Betyg C – fullständig funktionalitet, ren kod, och dokumentation.
